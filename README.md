# Omato Dashboard - Power BI Project

## Overview
This project showcases an interactive Power BI dashboard for Omato restaurants. 
It visualizes key business metrics such as sales, transactions, visits, and payment modes.

## Project Structure
- **video/**: Project demo video
- **data/**: Sales, transactions, and payment data
- **images/**: Dashboard screenshots
- **reports/**: PDF summary reports
- **code/**: Power BI PBIX files and DAX scripts

## Key Features
- Interactive slicers for restaurants, payment modes, and dates
- Visualizations: Sales trends, transaction analysis, visit patterns
- KPI metrics for business performance
