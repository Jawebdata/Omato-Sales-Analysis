# Omato Dashboard - Power BI Project

This is a Power BI project where we have built an interactive dashboard for Omato restaurants to analyze **sales, transactions, visits, and payment modes**.

📌 **Features**
- Customer and Restaurant Data Analysis  
- Sales and Transactions Tracking  
- Payment Mode Analysis  
- Interactive Slicers and KPI Metrics  
- Visualizations: Bar chart, Line chart, Pie chart, Matrix  

🛠️ **Tools Used**
- Power BI Desktop  
- DAX Queries  
- Excel / CSV (Data Files)
